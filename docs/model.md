# Layered Earth — 数理モデル v0.1

## 定義

有効セル集合を M、標高を h、層幅を Δ=5 m とする。

$$L(p)=\lfloor h(p)/\Delta\rfloor,\quad R_k=\{p\in M:k\Delta\le h(p)<(k+1)\Delta\}.$$

各 R_k の4近傍または8近傍の連結成分が「飛地」。標高の負値は0へ丸めない。
CLIは初期値で h≥0 を選択するが、これは陸海マスクではない。
海面下の陸地も除外し、標高0の海セルを含み得る。陸地限定の結論には独立マスクが必要。

緯度経度セルの面積は球面近似で計算する。

$$A=R^2|\sin\phi_N-\sin\phi_S|\,|\lambda_E-\lambda_W|,\quad R=6371.0088\text{ km}.$$

角度はラジアン。楕円体面積、地表斜面積とは異なる。

## 接続

異なる成分のセルが辺を共有するとき接触辺を作る。対角接触は接触辺にしない。
低い層から高い層へ向けた接触グラフはDAG。粗いラスターでは複数層を飛び越す辺があり、
`layer_jump`に保持する。途中の層を補間・捏造しない。
これは地形の接触グラフであり、交通・物流の移動可能グラフではない。
同層間の往復航路を加えたグラフは一般にDAGではない。

## 現在の実装範囲

- 地域DEMの全占有層、飛地数、球面面積ランキング、上向き接触辺。
- NPZとオプションのEPSG:4326 GeoTIFF入力。
- CSV、出典と入力SHA-256、PNG/SVG、画像埋め込みMarkdownを自動生成。
- 4/8近傍切替。全画像は入力DEMから生成する。

## まだ未実施

NOAAへの接続がこの実行環境でタイムアウトしたため、実データ結果画像はまだない。
テスト用小配列は数学的検証専用であり、地球の観測結果として提示しない。

全球の経度シーム接続・極点処理は未実装。全球入力は明示的に拒否する。
現在の成分抽出は占有層数 K × セル数 N の走査で O(KN)。地域プロトタイプ向けで、
全球15秒DEMの実運用にはタイル境界を統合するラベリングとストリーミング集計が必要。
地域境界で切れた成分は、領域外で繋がる可能性がある。

## 研究の次段階

1. 実データの小領域で画像・面積保存則を検証。
2. 同一範囲で4/8近傍、水平解像度、層幅5/10/20mの感度分析。
3. 独立陸海マスクとDEM誤差モデルを導入。
4. 全球シーム・極・タイル境界をテスト後、全球へ拡張。

5mの分類幅は5mの測量精度を意味しない。飛地数は解像度と連結規則に依存する。
